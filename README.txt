# Agenda — PWA para GitHub Pages

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie **todos os arquivos e pastas** deste ZIP para a raiz do repositório.
3. Em Settings → Pages, escolha `Deploy from a branch`, selecione `main` e `/ (root)`.
4. Abra a URL HTTPS do GitHub Pages no Safari do iPhone.

## Instalar no iPhone
No Safari: **Compartilhar → Adicionar à Tela de Início → Adicionar**.

Importante: não abra o `index.html` como arquivo local. PWA/service worker exige HTTPS (GitHub Pages fornece HTTPS).
